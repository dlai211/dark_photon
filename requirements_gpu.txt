# =============================================================================
# dark_photon - GPU (CUDA) Python environment
# =============================================================================
# Same package set as requirements.txt, with CUDA-enabled TensorFlow.
# Versions are pinned to pixi/pixi.lock (the project's locked conda-forge
# environment, Python 3.12.13); the DNN training runs in
# code_jet_faking_ML/ML/wandb/*/files/requirements.txt used TensorFlow 2.19.1.
# numpy, keras and uproot are the exceptions: numpy and keras are pinned to
# versions compatible with the TensorFlow 2.19.1 wheel on PyPI, and uproot is
# pinned to 5.7.7 because 5.7.3 (in pixi.lock) was yanked (see comments below).
#
# Requirements:
#   * Python 3.12 (TensorFlow 2.19 supports 3.9-3.12 only)
#   * Linux or WSL2. Native Windows TensorFlow >= 2.11 has no GPU support.
#   * NVIDIA driver >= 525.60.13 (Linux) / >= 528.33 (WSL2).
#     TensorFlow 2.19 is built against CUDA 12.5 and cuDNN 9.3; the
#     tensorflow[and-cuda] extra installs the matching NVIDIA pip wheels,
#     so no system-wide CUDA toolkit is required.
#
# Install:
#   python3.12 -m venv .venv
#   source .venv/bin/activate
#   pip install -r requirements_gpu.txt
#
# Verify the GPU is visible:
#   python -c "import tensorflow as tf; print(tf.config.list_physical_devices('GPU'))"
#   python -c "import xgboost as xgb; print(xgb.build_info())"
#
# PyROOT: `import ROOT` is used by the analysis / post-processing scripts
# (simple_plot.py, postprocessing/, code/pyroot.py, code/Save*.py, code/test.py,
# test.ipynb, code_old/cross_check_w_pyroot.py). PyROOT is NOT on PyPI: the
# PyPI project called "root" is an unrelated package, so do not `pip install
# root`. Install PyROOT from conda-forge or an LCG/CVMFS stack instead:
#   conda install -c conda-forge root
# Everything else in this file installs with pip alone.
# =============================================================================
